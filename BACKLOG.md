Run its catalogue-only checks before the request loop and prove that stale, redundant or lost retirement status makes zero lab-list requests; retain the final values-against-catalogue gate before write.
2. **Consider metric help in the column picker.** *(metric help, 2026-08-05)* Every published range metric now has one factual explanation in the reusable registry, but this delivery deliberately stops at the sidebar and Add-filter dialog (docs/app.md §Filters). The column picker remains a dense selection surface with an established direction mark and keyboard path; adding another focus stop to every row may cost more than it clarifies. Test that trade-off on a phone and with a keyboard before reusing the small `?` there, and leave the picker unchanged if the explanation is better discovered where the metric is actually filtered.
3. **Open Graph tags.** *(UX polish, 2026-07-28)* The page has a title and a favicon, so a shared link previews as *something* (docs/app.md §Sharing is copying the address bar), but there are no `og:`/`twitter:` tags and therefore no card. Deferred rather than done because it needs an image, and an image needs a decision about what this tool looks like — a screenshot dates, and there is no logo.
